Q1: Write a program to concatenate two strings.

```py
first_name = "MSK"
last_name = "Institute"
full_name = first_name + " " + last_name
print(full_name)  # Output: MSK Institute
```

Q2: Write a program to find the length of a string.

```py
course = "Python Basics"
print(len(course))  # Output: 13
```

Q3: Write a program to convert a string to uppercase.

```py
course = "Python Basics"
print(course.upper())  # Output: PYTHON BASICS
```

Q4: Write a program to convert a string to lowercase.

```py
course = "Python Basics"
print(course.lower())  # Output: python basics
```

Q5: Write a program to replace a substring in a string.

```py
course = "Python Basics"
new_course = course.replace("Basics", "Advanced")
print(new_course)  # Output: Python Advanced
```


Q6: Write a program to split a string into a list of substrings.

```py
course = "Python Basics Course"
words = course.split()
print(words)  # Output: ['Python', 'Basics', 'Course']
```

Q7: Write a program to join a list of strings into a single string.

```py
words = ["Python", "Basics", "Course"]
course = " ".join(words)
print(course)  # Output: Python Basics Course
```

Q8: Write a program to check if a string starts with a specific substring.

```py
course = "Python Basics"
print(course.startswith("Python"))  # Output: True
```

Q9: Write a program to check if a string ends with a specific substring.

```py
course = "Python Basics"
print(course.endswith("Basics"))  # Output: True
```

Q10: Write a program to find a substring within a string.

```py
course = "Python Basics"
print(course.find("Basics"))  # Output: 7
```
