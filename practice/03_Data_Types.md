Q1: Write a program to check the data type of a variable.

```py
x = 5
print(type(x))  # Output: <class 'int'>
```

Q2: Write a program to demonstrate string data type.

```py
name = "MSK Institute"
print(type(name))  # Output: <class 'str'>
```

Q3: Write a program to demonstrate float data type.

```py
pi = 3.14
print(type(pi))  # Output: <class 'float'>
```

Q4: Write a program to demonstrate boolean data type.

```py
is_active = True
print(type(is_active))  # Output: <class 'bool'>
```

Q5: Write a program to demonstrate list data type.

```py
courses = ["Python", "JavaScript", "Django"]
print(type(courses))  # Output: <class 'list'>
```

Q6: Write a program to demonstrate tuple data type.

```py
coordinates = (10, 20)
print(type(coordinates))  # Output: <class 'tuple'>
```

Q7: Write a program to demonstrate dictionary data type.

```py
student = {"name": "Sumit", "age": 21}
print(type(student))  # Output: <class 'dict'>
```

Q8: Write a program to demonstrate set data type.

```py
unique_numbers = {1, 2, 3, 4, 5}
print(type(unique_numbers))  # Output: <class 'set'>
```

Q9: Write a program to convert an integer to a string.

```py
num = 100
num_str = str(num)

```

Q10: Write a program to convert a string to a float.

