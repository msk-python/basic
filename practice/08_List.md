Q1: Write a program to create and print a list.

```py
courses = ["Python", "JavaScript", "Django"]
print(courses)  # Output: ['Python', 'JavaScript', 'Django']
```

Q2: Write a program to access elements in a list.

```py
courses = ["Python", "JavaScript", "Django"]
print(courses[0])  # Output: Python
print(courses[1])  # Output: JavaScript
```

Q3: Write a program to append an element to a list.

```py
courses = ["Python", "JavaScript"]
courses.append("Django")
print(courses)  # Output: ['Python', 'JavaScript', 'Django']
```

Q4: Write a program to remove an element from a list.

```py
courses = ["Python", "JavaScript", "Django"]
courses.remove("JavaScript")
print(courses)  # Output: ['Python', 'Django']
```

Q5: Write a program to insert an element at a specific position in a list.

```py
courses = ["Python", "Django"]
courses.insert(1, "JavaScript")
print(courses)  # Output: ['Python', 'JavaScript', 'Django']
```

Q6: Write a program to sort a list in ascending order.

```py
numbers = [5, 3, 8, 1, 2]
numbers.sort()
print(numbers)  # Output: [1, 2, 3, 5, 8]
```

Q7: Write a program to reverse a list.

```py
numbers = [1, 2, 3, 4, 5]
numbers.reverse()
print(numbers)  # Output: [5, 4, 3, 2, 1]
```


Q8: Write a program to find the length of a list.

```py
courses = ["Python", "JavaScript", "Django"]
print(len(courses))  # Output: 3
```

Q9: Write a program to iterate through a list using a for loop.

```py
courses = ["Python", "JavaScript", "Django"]
for course in courses:
    print(course)
```

Q10: Write a program to check if an element exists in a list.

```py
courses = ["Python", "JavaScript", "Django"]
print("Python" in courses)  # Output: True
print("Java" in courses)    # Output: False
```
